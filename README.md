# StoryWeaver

“StoryWeaver”是一款完全在本地运行的文游剧情分支与数值逻辑编辑器。简单来说，就是带数值的思维导图，属于文游特化版。它使用 .NET 8 启动一个本地服务，再由浏览器打开编辑界面；剧情数据默认保存在程序旁边的 `cache` 文件夹，不会上传到第三方服务。

## 快速上手

安装exe文件后双击（双击前记得给exe找个好地方……因为第一次启动会自动拉一个cache文件夹出来哦），复制弹窗中给出的网址在浏览器打开即可使用。使用途中不要关闭弹窗。

## 功能概览

- 从元节点向右建立剧情节点，支持多分支、收束，以及按点击顺序连接两个已有剧情节点。
- 节点名称、详细备注、节点与备注全文查找。
- 分支线文字、自动延长的分支线、分支修剪和删减有内容节点时的二次确认。
- 元节点集中管理数值类和初始值。
- 分支线与数值节点可配置数值变化。
- 数值锁支持且、或、异或、非、嵌套条件组、范围判断、变量比较和高级表达式。（这部分我测试的比较少……反正能跑）
- 按实际路径计算确定值或理论上下限。
- “检查通路”可获取报告，查看因数值锁而无法进入的节点。
- 每隔 5 分钟自动备份，关闭网页时也会尝试保存；下次打开默认恢复最近缓存。（但还是手动导出比较安全就是了）
- 导入和导出可供 AI 阅读的 `.storymap.json` 逻辑文件。

## 使用提示

1. 数值类只能在元节点侧栏中添加、改名、修改初始值或删除。
2. 点击节点右侧的 `＋` 创建子节点。
3. 点击分支线进行编辑；鼠标移到分支线上后，线下方的 `−` 用于修剪。
4. 选中分支线后，可使用“插入数值节点”把一个仅改变数值的事件插入现有路径。
5. 点击“收束”，选中至少两个来源节点，再新建收束节点或指定已有节点。
6. 点击“连线”，先点起点剧情节点、再点终点剧情节点；系统会阻止重复同向连接和循环连接。
7. 拖动画布空白处平移，滚轮缩放；`Ctrl+F` 查找，`Ctrl+S` 保存。

缓存位于 EXE 同一文件夹下的 `cache` 文件夹。自动备份历史位于 `cache/history`。

## 从源码构建

需要 Windows、.NET 8 SDK，以及运行模型测试所需的 Node.js：

```powershell
dotnet publish .\StoryWeaver.csproj -c Release -r win-x64 --self-contained true -o .\publish
```

发布结果位于 `publish\StoryWeaver.exe`，这是可以直接分发的自包含单文件程序。运行后保持启动窗口开启，再把窗口显示的本地网址复制到浏览器。

模型逻辑测试：

```powershell
node .\tests\model.test.cjs
```
